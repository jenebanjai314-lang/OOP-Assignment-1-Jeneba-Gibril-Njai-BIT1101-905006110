Patient Record Management System

Project Description
The Patient Record Management System is a simple Python project developed using Object-Oriented Programming concepts. It helps users register patients, display patient records, search for patients, and update their information.

Technologies Used
- Visual Studio Code
- Python
- Git/GitHub

Features
1. Register a new patient.
2. Display all patient records.
3. Search for a patient using a unique ID.
4. Update patient information.
5. Count registered patients.

OOP Concepts
- Classes and objects
- Attributes and methods
- Instance methods
- Class methods

Data Structure
A Python list stores multiple Patient objects.
Digital Public Goods Principles

- Open-source code suitable for sharing on GitHub.
- Simple, accessible text-based interface.
- Fictional data to avoid exposing sensitive patient information.
- Modular classes that can be reused and extended.


Example
The user can register a fictional patient with an ID, name, age, gender, and reason for visit, then search for or update the record.

Limitation
Records are stored in memory and are lost when the program closes. This version is intended for educational purposes only.
